---
name: design-system-audit
description: Audit Taskio UI and create/improve design system rules, components, states, data patterns, forms, tables, badges, cards, modals, and dark mode.
---

Use `ux-ui-agent`.

Workflow:
1. Inspect current UI components and pages.
2. Identify repeated patterns.
3. Identify inconsistencies and usability issues.
4. Map external UX principles to Taskio.
5. Propose design tokens/components/states.
6. Create or update `docs/design-system/`.
7. Produce frontend-agent handoff.
8. Do not implement backend logic.
