---
name: add-test-coverage
description: Add high-value backend/frontend tests for a Taskio refactor or feature.
---

Use `testing-agent`.

Workflow:
1. Inspect current test setup and commands.
2. Identify behavior to protect.
3. Add minimal high-value tests.
4. Prefer backend feature tests first.
5. Add frontend tests only where stable and valuable.
6. Run/describe validation commands.
7. Report remaining gaps.
