---
name: implementation-planning
description: Interactive planning workflow for features, refactors, architecture decisions, UX flows, tests, docs, and multi-agent implementation plans.
---

Use `planning-agent`.

Hard rules:
- Do not edit code.
- Do not implement.
- Challenge assumptions.
- Ask only important clarifying questions.
- Compare options.
- Recommend one path.
- Produce an implementation-ready plan split by agents.
- End by asking for approval.

The plan must include:
- Goal restatement.
- Assumptions.
- Missing information.
- Critical review.
- Options with pros/cons.
- Recommendation.
- Agent-specific task list.
- Execution order.
- Acceptance criteria.
- Risks and rollback.
