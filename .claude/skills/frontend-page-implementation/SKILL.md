description: Implement a Vue page/component from approved UX/UI handoff and backend API contract.
---

Use `frontend-agent`.

Workflow:
1. Read approved UX/UI plan.
2. Read backend API contract/docs.
3. Inspect existing components and modules.
4. Implement using Vue/Tailwind/Pinia patterns.
5. Cover states and accessibility.
6. Run/describe frontend validation.
7. Ask testing-agent for tests.
8. Ask documentation-agent for component docs.
