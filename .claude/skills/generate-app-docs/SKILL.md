---
name: generate-app-docs
description: Generate in-repository/in-app documentation for backend API, frontend components, design system, and architecture decisions.
---

Use `documentation-agent`.

Workflow:
1. Inspect actual implementation.
2. Identify docs target: backend, frontend, design system, architecture, decision.
3. Write docs with examples.
4. Mark planned vs implemented behavior clearly.
5. Link docs to code when possible.
6. Suggest in-app docs UI tasks for frontend-agent if needed.
