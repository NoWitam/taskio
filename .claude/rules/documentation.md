# Documentation Rules

- Documentation belongs in the repository and should be suitable for in-app rendering.
- Document implemented behavior.
- Mark planned behavior as planned.
- Include examples for API endpoints and components.
- Keep docs aligned with backend/frontend code.
- Maintain architecture decisions in `docs/decisions/`.
- Maintain accepted external AI/UX/reference links in `docs/ai/reference-links.md`.
